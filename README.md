# dabbir-reports

تقارير حالة دبّر، مُعقَّمة للنشر العام.

[`LATEST.md`](LATEST.md) يحمل آخر تقرير ويُحدَّث مع كل إعلان.

**ما لا يوجد هنا إطلاقًا:** أسرار، مفاتيح، أرقام هواتف، أسماء عملاء،
معرّفات حسابات أو طلبات، أو أي محتوى محادثات.

الأرقام المنشورة إما **مقيسة** من بياناتنا أو معلَّمة **«تقديري»** صراحةً.
